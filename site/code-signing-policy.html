Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status. The application to SignPath Foundation is in progress. Until it is accepted, the Windows files on the releases page are not signed, and Windows shows "Unknown publisher" when the installer starts.

What is signed

The Windows installer (bootpick-…-x86_64-windows-setup.exe) and the settings app it installs (bootpick-config.exe). Both are built from the source code in the bootpick repository by its Windows workflow on GitHub-hosted runners; nothing built on a developer's computer is signed. The boot menu itself (bootpick.efi) is not signed for Secure Boot.

The installer also carries, unchanged, the file system drivers in assets/drivers of the repository, which come from other open-source projects.

Team roles

  • Committers and reviewers: Devace-93 (Enrique Magallón)
  • Approvers: Devace-93 (Enrique Magallón)

Changes proposed by anyone else arrive as pull requests and are reviewed before they are merged. Every release is approved by hand before it is signed.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The boot menu, the settings app and the installer make no network connections. This website is separate from the program: its Download button asks GitHub for the list of releases.

What the installer changes

The installer shows what it will do before it does it: it copies the boot menu to the EFI System Partition, adds a firmware boot entry and puts it first, and installs the settings app. The same installer, and the settings app, remove all of it again.

Reporting a problem

If you believe a signed file does not match this policy, open an issue at github.com/Devace-93/bootpick/issues.
