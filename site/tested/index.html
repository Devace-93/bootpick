The settings app was used on Pop!_OS 24.04 (COSMIC, Wayland) and on elementary OS, both editing the same installation.

Tried it on something else? Open an issue with the computer model, firmware vendor (shown in \EFI\bootpick\bootpick.log), the systems you start and whether the mouse worked, and it will be added here.
